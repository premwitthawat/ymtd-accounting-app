# ออกใบแจ้งหนี้ค่าบริการรายเดือน (FlowAccount → Google Drive)

สองสคริปต์ในโฟลเดอร์นี้ทำงานกับ FlowAccount **production** โดยตรง ไม่ส่งอะไรหาลูกค้า
ไม่แตะ LINE ไม่แตะฐานข้อมูลของแอป

> **⚠ ตั้งแต่ ต.ค. 2569: ระบบ cloud (edge function `flowaccount-invoices` + cron วันที่ 1)
> เป็นผู้ออกใบแจ้งหนี้/ใบวางบิลรวมตัวจริง** สำหรับบริษัทที่กรอก `monthly_fee` ในแอปแล้ว —
> ห้ามใช้ `sheet-invoices.mjs apply` / `create-invoices.mjs create` ซ้อนกับบริษัทเหล่านั้น
> (สองระบบไม่รู้จักกัน จะได้ใบซ้ำ) สคริปต์ในนี้เหลือหน้าที่: ดึง PDF ลง Drive, ตรวจทาน,
> และดูแลบริษัทที่ยังออกมือ/ส่งแยก

| สคริปต์ | ใช้เมื่อ |
|---|---|
| `sheet-invoices.mjs` | เทียบชีตกับ FlowAccount สำหรับรายที่ยังออกมือ (ส่งแยก) · ดึง PDF ลง Drive |
| `create-invoices.mjs` | โคลนชุดเดือนก่อนทั้งชุดแบบไม่ดูชีต (เลิกใช้เมื่อ cloud ดูแลครบทุกราย) |
| `fill-companies.mjs` | เติม master data บริษัทในแอปจาก contact จริงใน FlowAccount + ชีต |

## เตรียมครั้งเดียว

1. คัดลอก `.env.example` เป็น `.env` ใส่ `FLOWACCOUNT_CLIENT_ID` / `FLOWACCOUNT_CLIENT_SECRET`
   จากอีเมล "ข้อมูล Production API" ของ FlowAccount (`.env` ถูก gitignore — ห้าม commit)
2. Google Drive for desktop ต้องล็อกอินและมองเห็น `G:\My Drive\…\ใบแจ้งหนี้+ใบเสร็จรับเงิน`
3. Node ≥ 20 และ Python 3 ที่มี `openpyxl` (`pip install openpyxl`) สำหรับอ่าน xlsx

## ทุกต้นเดือน

1. กรอก `ใบแจ้งหนี้.xlsx` ชีต `ปี<พ.ศ.>` คอลัมน์ **เดือนบริการ** (เดือนที่จะเก็บเงิน = เดือนก่อนวันที่ออก):
   - บล็อก **ใบแจ้งหนี้**: ยอดค่าบริการ → จะมีใบแจ้งหนี้ 1 ใบ · **ว่างหรือ 0 = ไม่ออกเดือนนี้**
   - บล็อก **ใบวางบิล**: ยอดรวมที่จะวางบิล (ใบที่ยังค้างชำระทั้งหมด + เดือนนี้) → ออกใบวางบิลรวม 1 ใบ
   - ต้องมี **เลขผู้เสียภาษี** ในคอลัมน์ C (ถ้าไม่มี สคริปต์จะเทียบชื่อให้ แต่ไม่แน่นอนเท่า)
   - คอลัมน์ "สถานะ" (ส่งแยก ฯลฯ) เป็นโน้ตของสำนักงาน สคริปต์ไม่ใช้
2. dry-run — ดูว่าจะสร้าง/ลบ/วางบิลอะไร (ยังไม่แตะอะไร):
   ```powershell
   node scripts/monthly-invoices/sheet-invoices.mjs plan --target 2026-10
   ```
3. ทำจริง:
   ```powershell
   node scripts/monthly-invoices/sheet-invoices.mjs apply --target 2026-10 --yes
   ```
   รันซ้ำได้: รอบต่อไปจะเห็น "ตรง" ทั้งหมดและดึงเฉพาะ PDF ที่ยังขาด

`--target` = เดือนที่ *ออก* เอกสาร (ลงวันที่ 1) · ชีตที่อ่าน = คอลัมน์เดือนก่อนหน้า · ใส่ `--date YYYY-MM-DD` ถ้าไม่ใช่วันที่ 1

## กติกาที่สคริปต์ยึด

- **ต้นแบบ** ของแต่ละบริษัท = ใบแจ้งหนี้รายเดือนของเดือนก่อน (contact, ที่อยู่, หัก ณ ที่จ่าย, เครดิต)
  บริษัทใหม่ที่ไม่เคยมีใบ → รายงานว่า "ทำเอง" ให้ออกใบแรกในเว็บก่อน
- **ยอดไม่ตรง** ระหว่างชีตกับใบที่มีอยู่ → รายงานอย่างเดียว ไม่แก้เอง (แก้ยอดในเว็บหรือลบแล้วรันใหม่)
- **ใบวางบิล** = รายการ: ใบแจ้งหนี้ที่ยังค้าง (สถานะ ≠ ชำระแล้ว) ก่อนเดือนนี้ + ค่าบริการเดือนนี้;
  ถ้ารวมแล้วไม่เท่ายอดในชีต → รายงาน ไม่ออก (มักเป็นเพราะมีใบค้างที่ชีตลืมนับ หรือรับชำระแล้วแต่ยังไม่บันทึกใน FlowAccount)
- **ลบ** เฉพาะใบสถานะรอดำเนินการ (FlowAccount ลบแบบ soft และจะนำเลขกลับมาใช้ถ้าเป็นใบล่าสุด)
  PDF ของใบที่ลบจะถูกลบออกจาก Drive ด้วย รวมถึงไฟล์ที่เลขไม่ตรงกับเจ้าของแล้ว
- **โฟลเดอร์ปลายทาง** หาจากที่ที่ไฟล์เดือนก่อนถูกเก็บ แล้วสร้าง `MM.YYYY` (พ.ศ.) ของเดือนถัดไปข้าง ๆ
- **ชื่อไฟล์** ตามที่เว็บ FlowAccount ตั้ง (`<ผู้ออก>_<เลขที่>_<ลูกค้า>.pdf`) — ถ้ายาวเกิน 255 ไบต์
  (Drive ปฏิเสธ) จะตัดชื่อผู้ออกออก เหมือนที่สำนักงานทำกับบริษัทชื่อยาว
- ไม่แตะใบที่ออกระหว่างเดือน (ค่าหนังสือรับรอง, เปลี่ยนกรรมการ ฯลฯ) — ดูเฉพาะรายการ "ประจำเดือน" ที่ออกวันที่ 1

## log ของแต่ละรอบ

`runs/<target>-sheet.json` (gitignore) — สร้าง/ลบ/วางบิลอะไรไปบ้าง พร้อม recordId และ path ของ PDF
ถ้าจะย้อนกลับ: เอกสารที่ยังรอดำเนินการลบได้ในเว็บ FlowAccount

## หมายเหตุ API (production)

- Token URL คือ `https://openapi.flowaccount.com/v1/token` (ไม่ใช่ `/token` — ตอบ 403)
- รายการเอกสาร: `GET /tax-invoices` และ `GET /billing-notes` ด้วย `range=5&startDate&endDate&pageSize=100`
- สถานะเป็นตัวเลข: 1 = รอดำเนินการ/ยังไม่จ่าย, 9 = ชำระแล้ว (มี 7 = ค้างบางส่วน?) — "ค้าง" = ทุกอย่างที่ไม่ใช่ 9
- ใบวางบิลที่เว็บสร้าง = SimpleDocument ที่มี items หลายบรรทัด ไม่ได้อ้างอิงใบแจ้งหนี้ผ่าน documentReference
- rate limit 100 ครั้ง/นาที — สคริปต์ถอยตาม `Retry-After` เอง
