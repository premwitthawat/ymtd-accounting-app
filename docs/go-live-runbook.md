## ขั้น 1 — เอาโค้ดขึ้น main **[เคลม]**

ไม่มีเมนูให้กด เป็นคำสั่ง git ที่ผมรันให้ — สั่งว่า "merge ขึ้น main" คำเดียว

ผมจะ: merge `feat/flowaccount-receipt` → `main` → push
GitHub Actions จะ deploy หน้าเว็บอัตโนมัติภายใน 1–2 นาที

> ⚠️ หลัง push หน้าเว็บจะมีปุ่มใหม่ (ใบแจ้งหนี้/ใบเสร็จ) โผล่ให้พนักงานเห็นทันที
> แต่ยังกดไม่ได้จนกว่าจะทำขั้น 2 กับ 3 เสร็จ — ถ้าไม่อยากให้เห็นก่อนเวลา
> ให้ทำขั้น 2–3 ต่อทันทีในวันเดียวกัน

## ขั้น 2 — รัน migration ในฐานข้อมูล

เพิ่มตาราง/คอลัมน์ที่ระบบใหม่ต้องใช้ ทำครั้งเดียว

1. เปิด https://supabase.com/dashboard → เลือกโปรเจ็ก **ymtd-accounting-app**
2. เมนูซ้าย ไอคอน **SQL Editor** (รูป `>_`)
3. กด **New query**
4. เปิดไฟล์ `migrations-016-020.sql` ที่ผมเตรียมไว้ (ผมส่ง path ให้) **คัดลอกทั้งไฟล์** มาวาง
5. กด **Run** (หรือ Ctrl+Enter)

ต้องขึ้น `Success. No rows returned` — ถ้าขึ้นแดง **หยุด แล้วส่งข้อความ error มาให้ผมดู**
อย่ารันซ้ำ

ไฟล์ครอบทั้งก้อนด้วย `begin; ... commit;` ถ้าพังกลางทางจะย้อนกลับให้เองทั้งหมด
ไม่มีสภาพครึ่งๆ กลางๆ

## ขั้น 3 — Deploy edge functions + ตั้งค่า secrets

ส่วนนี้ทำผ่าน terminal ไม่มีเมนูในเว็บ **ผมรันให้ได้ [เคลม]** แต่ต้องใช้สิทธิ์เข้าถึง
โปรเจ็ก production ซึ่งต้องได้รับอนุญาตจากคุณก่อน

### สิ่งที่ต้องเตรียม

- **Access token** ของ Supabase: https://supabase.com/dashboard/account/tokens
  → Generate new token → คัดลอกมาให้ (เก็บเป็นความลับ ห้ามส่งในกลุ่ม LINE)
- **Production client_id / client_secret** จากขั้น 0
- **เลข bank account id** — ดูวิธีหาด้านล่าง

### คำสั่ง

```bash
supabase login                      # ใส่ access token
supabase link --project-ref <ref>   # ref อยู่ใน URL ของ dashboard

# ตั้งค่าลับ (ไม่โผล่ในโค้ด ไม่โผล่ในเว็บ)
supabase secrets set \
  FLOWACCOUNT_CLIENT_ID=<production client id> \
  FLOWACCOUNT_CLIENT_SECRET=<production client secret> \
  FLOWACCOUNT_BASE_URL=https://openapi.flowaccount.com/v1 \
  FLOWACCOUNT_TOKEN_URL=https://openapi.flowaccount.com/token \
  FLOWACCOUNT_MOCK=false \
  FLOWACCOUNT_BANK_ACCOUNT_ID=<เลขจากด้านล่าง>

# deploy ทั้ง 4 ตัว
supabase functions deploy flowaccount-invoices
supabase functions deploy flowaccount-issue-receipt
supabase functions deploy line-webhook
supabase functions deploy admin-users
```

### หาเลข bank account id ยังไง

บัญชีกสิกร 057-3-47559-3 ใน FlowAccount **ตัวจริง** มี id คนละเลขกับ sandbox
พอได้ production credentials แล้วผมยิงถามให้ได้ใน 10 วินาที
(`GET /bank-accounts`) แล้วบอกเลขให้

ถ้าไม่ตั้งค่านี้ ใบเสร็จยังออกได้ปกติ แต่บัญชีสำนักงานจะไม่บันทึกว่าเก็บเงินแล้ว

### ต้องเพิ่ม secret ใน GitHub ด้วย

สำหรับ cron ที่ออกใบแจ้งหนี้ทุกวันที่ 1:
GitHub repo → **Settings** → **Secrets and variables** → **Actions** → New secret
- `SUPABASE_URL`
- `SUPABASE_SERVICE_ROLE_KEY` (Dashboard → Project Settings → API)

## ขั้น 4 — ทดลองกับ เจน นุ่น โบว์ ก่อน

ระบบออกแบบมาให้ทดลองวงแคบได้โดยไม่ต้องแก้โค้ด — อาศัยกฎ 2 ข้อที่มีอยู่แล้ว:

1. **คำสั่ง `paid` ในแชท ใช้ได้เฉพาะคนที่ผูก LINE ID ไว้แล้วเท่านั้น**
   ผูกแค่ 3 คนนี้ คนอื่น (รวมลูกค้า) สั่งไม่ได้ ระบบเมินเงียบๆ
2. **ใบแจ้งหนี้ออกเฉพาะบริษัทที่กรอกค่าบริการรายเดือนไว้แล้ว**
   ยังไม่กรอกใคร = ยังไม่มีใบแจ้งหนี้ออกไปหาลูกค้าเลย ปลอดภัย 100%

### ขั้นตอนทดลอง

**ก. ผูก LINE ID 3 คน**
1. ให้ เจน นุ่น โบว์ **แอดบอทเป็นเพื่อน** แล้วทักแชทส่วนตัว (1:1) พิมพ์ `myid`
2. บอทตอบกลับเป็นรหัสขึ้นต้นด้วย `U` ตามด้วยตัวอักษร/ตัวเลข 32 ตัว
3. ให้แต่ละคนส่งรหัสมาให้
4. เปิดเว็บ → ไอคอน **เฟือง** (จัดการผู้ใช้) → ช่อง LINE ID ของแต่ละคน → วาง → บันทึก

**ข. ทดลองออกใบเสร็จค่าภาษี** (ไม่กระทบลูกค้า)
- เลือกบริษัททดลอง 1 ราย กรอก **เลขผู้เสียภาษี** กับ **ที่อยู่** ในหน้าแก้ไขบริษัท
- กดปุ่ม **ออกใบเสร็จ** ที่รายการที่ชำระแล้ว → ใส่ยอด → ยืนยัน
- เช็คใน FlowAccount ว่าเอกสารออกถูกต้อง

**ค. ทดลองใบแจ้งหนี้รายเดือน**
- กรอก **ค่าบริการรายเดือน** ให้บริษัททดลองรายเดียวก่อน
- สั่งออกใบแจ้งหนี้ → ตรวจ PDF → ค่อยลองสั่ง `paid` ในกลุ่ม

> ⚠️ พอกรอกค่าบริการรายเดือนแล้ว **วันที่ 1 เดือนถัดไประบบจะส่งใบแจ้งหนี้เข้ากลุ่ม LINE
> ของบริษัทนั้นอัตโนมัติ** ถ้ายังไม่พร้อมให้ลูกค้าเห็น อย่าเพิ่งกรอก
> หรือลบเลขค่าบริการออกก่อนสิ้นเดือน

## ขั้น 5 — เปิดใช้จริงทั้งหมด

พอ 3 คนใช้แล้วไม่มีปัญหา:
1. ผูก LINE ID พนักงานที่เหลือ
2. กรอกข้อมูลลูกค้าครบทุกราย — **เลขผู้เสียภาษี / ที่อยู่ / ค่าบริการรายเดือน /
   หัก ณ ที่จ่าย 3% หรือไม่**
3. ประกาศให้ทีมทราบว่าใช้คำสั่ง `paid` ในกลุ่มได้แล้ว

บริษัทที่ข้อมูลไม่ครบระบบจะข้ามให้เอง พร้อมบอกว่าขาดอะไร ไม่ทำให้ทั้งรอบล้ม —
กรอกทีละรายได้ ไม่ต้องรอครบ

## ถ้าเกิดปัญหา

| อาการ | ทำอะไร |
|---|---|
| กดปุ่มแล้วขึ้น error สีแดง | ส่งภาพ error มา อย่ากดซ้ำรัวๆ |
| ใบเสร็จออกแล้วแต่ไม่มี PDF | กดปุ่ม "ดึง PDF ใบเสร็จอีกครั้ง" — ไม่ออกเอกสารซ้ำ |
| สั่ง `paid` แล้วเงียบ | คนสั่งยังไม่ได้ผูก LINE ID (ขั้น 4ก) |
| ออกเอกสารผิดยอด | **แก้ในระบบไม่ได้** ต้องออกใบลดหนี้ใน FlowAccount เอง — เลยมีหน้ายืนยันยอดก่อนออกทุกครั้ง |
